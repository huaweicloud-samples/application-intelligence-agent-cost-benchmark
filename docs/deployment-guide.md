# 部署指南

本实践为一个本地运行的 Python 命令行工具，无需部署云基础设施。本指南描述其安装、配置与运行方式。所有访问密钥与端点信息均为占位说明，不包含真实值。

## 1. 前置准备

| 项 | 要求 |
|---|---|
| 运行环境 | Python 3.10+ 与 pip；Linux / macOS / Windows 均可 |
| 版本控制 | Git（用于拉取任务仓库） |
| 编码助手 | 按评测模式安装对应助手并完成登录，例如 Kiro、Claude Code、Copilot、Codex、Cursor、Devin、OpenCode、pi 等 |
| 模型端点（可选） | 使用 `pi` 等需自指定端点的助手时，准备一个 OpenAI 兼容端点；本实践推荐华为云模型即服务（MaaS）接口 |
| 容器（可选） | 使用容器验证方式的任务需要 Docker |

## 2. 安装

在仓库根目录创建并激活虚拟环境后安装工具：

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e .
```

验证安装：

```bash
agent-cost-bench --help
```

## 3. 交互式运行（推荐）

仓库提供交互式脚本，引导完成配置与运行全流程：

```bash
./run.sh
```

脚本依次执行：

1. **运行前检查**：确认 `git`、`python3`、`curl` 等工具就绪（选用基于 npm 的助手时还需 `npm`），缺失项提前报告。
2. **安装准备**：在带时间戳的独立目录中克隆工具、创建虚拟环境、安装工具本体与所选助手。
3. **配置生成**：让你选择要对比的助手与模型，查询各助手可用的模型列表供选择，收集所需密钥，并生成有效的配置文件。
4. **执行与报告**：运行评测并生成对比报告。

使用自定义配置时可通过 `--config` 指向已有配置文件。

## 4. 手工配置运行

也可手工准备配置后运行，适合需要精细控制参数的场景。

1. 复制示例配置：

```bash
# 助手对比模式
cp config.cli-compare.example.yaml config.cli-compare.yaml
# 模型对比模式
cp config.model-compare.example.yaml config.model-compare.yaml
```

2. 按所选助手设置认证信息。各助手从其标准环境变量或登录态读取凭据，例如：

```bash
export OPENAI_BASE_URL="<你的OpenAI兼容端点>"
export OPENAI_API_KEY="<你的API密钥>"
```

> 使用华为云 MaaS 时，将端点指向其 OpenAI 兼容接口，并使用在控制台申请的 API 密钥。请勿把密钥写入配置文件或提交到版本库。

3. 运行评测：

```bash
agent-cost-bench cli-compare --config config.cli-compare.yaml
# 或
agent-cost-bench model-compare --config config.model-compare.yaml
```

## 5. 配置要点

| 配置项 | 说明 |
|---|---|
| `runners` / `models` | 参与对比的助手或模型列表 |
| `task_ids` | 本次运行的任务集合，建议先用小样本试运行 |
| `effort` | 推理投入级别，全局默认，任务内声明可覆盖 |
| `judge_cli_path` | 评分规则类任务使用的评审助手 |
| `workspace_base` | 任务工作区的根目录 |
| 验证方式 | 按任务声明选择 Python 测试、自定义评分、容器或评分规则 |

## 6. 验证运行结果

运行结束后检查：

- **对比报告**：包含各助手 / 模型在通过率、时延与用量上的对比结果。
- **逐运行日志**：`<输出目录>/<运行标识>.log`，记录每次运行的细节，便于回溯异常。
- **重复运行统计**：配置了重复次数时，报告给出通过率与置信区间，反映结果稳定性。

若结果异常，先查看逐运行日志定位是助手执行失败、验证配置有误还是端点不可用。

## 7. 自带任务与自定义任务

工具内置一组可直接使用的任务；也可接入自己的任务集：在配置中声明任务来源导入，或把任务转换到 `tasks/` 目录后编辑任务清单与测试夹具。自定义任务建议先单独验证其测试可运行，再纳入批量评测。

## 8. 常见问题

- **助手未找到**：确认助手已安装且可执行文件在 PATH 中，并完成登录。
- **模型端点不可用**：检查端点地址与密钥是否正确，网络是否可达。
- **任务验证失败**：查看逐运行日志与任务验证配置，确认测试命令在隔离工作区可执行。
- **运行耗时过长**：减少 `task_ids` 范围或降低重复次数，先用小样本验证流程。
